# data/sectores.geojson — PLACEHOLDER

Los 4 polígonos de este archivo (`comuna-2`, `comuna-3`, `comuna-17`,
`comuna-20`) son **rectángulos aproximados de ejemplo** alrededor de
Cali (lat ~3.40, lon ~-76.53), usados únicamente para poder desarrollar
y probar el backend end-to-end.

**No representan los límites reales de las comunas de Cali.** Antes de
producción, deben reemplazarse por los polígonos oficiales de DAGMA
(Departamento Administrativo de Gestión del Medio Ambiente de Cali) o,
en su defecto, por polígonos extraídos de OpenStreetMap (OSM), tal como
indica el Definition of Done en `03-Arquitectura-Backend.md`.
